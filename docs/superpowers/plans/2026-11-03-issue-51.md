# Chat tool cards keep their height in an overflowing thread (#51) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When the chat thread is long enough to scroll, every tool card (the ones with Undo) still shows at full height.

**Architecture:** `.chat-thread` (`app/globals.css:986`) is a flex column with a fixed height and `overflow-y: auto`. `.tool-card` (`app/globals.css:1053`) has `overflow: hidden`, so its automatic minimum height drops to 0. When the items overflow, flex shrinks them, and only the tool card can shrink to 0. The fix adds one rule, `.chat-thread > * { flex-shrink: 0; }`, so no thread item shrinks. A temporary Playwright script proves the bug before the fix and proves the fix after it.

**Tech Stack:** Next 16 (Turbopack dev), plain CSS in `app/globals.css`, Playwright (already a dev dependency, used by `scripts/screenshot-pass.ts`), tsx.

**Spec:** Issue #51 (`gh issue view 51`). The issue has no Done when section. The owner accepted the planner's proposed Done when and check method on 2026-11-03 (reply: "recommended"), and this plan records those decisions.

## Review Focus

1. **The remaining-today strip (`.rstrip`) and photo bubbles in a long thread.** They must keep their full height too. The rule targets every child of `.chat-thread`, so the script adds one `.rstrip` and checks it with the same measurement as the cards.
2. **Long text bubbles.** `flex-shrink` acts on the main axis (height) in a column. Bubble width and wrapping must not change. Check this in the screenshot.
3. **The empty-chat state (`.chat-empty`, `margin: auto`).** It must stay centered in an empty thread. Check this in the screenshot pass `chat.png` when the thread is empty. If the thread has history, say so at gate 2.
4. **The dimmed thread (`.chat-thread.dim`) when the attach menu is open.** The new rule uses the same selector root, so it must not change the dim style. The rule sets only `flex-shrink`, so no test is added for this.
5. **Scrolling to the newest message.** With no shrink, the thread's scroll height grows. The newest item must still be visible after a send. The script scrolls the thread to the bottom before the screenshot, and the last item it adds is a tool card. That card must be fully visible in `screenshots/chat-overflow.png`.
