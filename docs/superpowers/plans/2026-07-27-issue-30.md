# Calendar sheet: streak-only visual + pressable days with a per-day popup — Issue #30

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In the adherence calendar sheet, replace the text line under the month with a streak-only
visual, and turn the calendar day cells into real buttons that press with the #26 bubble feel and
open a popup describing that day.

**Architecture:** Three layers, in order. (1) The pure calendar model
(`lib/adherence-calendar.ts`) currently throws away each day's macros when it classifies history
into `on | onx | off`; it starts carrying them, so a pressed day has something to show without any
new query or route. (2) The under-month `.cal-sum` line is replaced by the owner-picked streak
visual, driven by the `summary.bestStreak` number that line already contained. (3) `.cal-cell`
stops being a `<div>` and becomes a `<button>` for every day that has something to say, gaining the
two-speed `:active` transform #26 shipped on the weekly strip, an `aria-label`, and a click that
opens the owner-picked popup. `targets` and today's live macros arrive as props from
`weekly-adherence.tsx`, which already holds both, so the server never changes.

**Tech Stack:** Next 16 App Router, React 19 client components, plain CSS in `app/globals.css`,
vitest for the pure model. No new dependency, no new API route, no new DB read.

// The calendar's states are finer than the strip's (two greens, a pre-history state),
// so map onto the strip's before reusing its copy. Extras are the one thing the shared
// verdict cannot know about, so they are appended here.
const TO_DAY_STATE: Partial<Record<CalDayState, DayCell["state"]>> = {
  on: "on-plan", onx: "on-plan", off: "off-plan", unlogged: "unlogged", today: "today",
};

/** The popup's verdict line, or null for a day the calendar has nothing to say about. */
export function calDayVerdict(
  state: CalDayState,
  consumed: Macros | null,
  targets: Macros,
): DayVerdict | null {
  const mapped = TO_DAY_STATE[state];
  if (!mapped) return null; // future | pre
  const v = dayVerdict({ date: "", dow: "", state: mapped, consumed }, targets);
  return state === "onx" ? { ...v, text: `${v.text}, with extras` } : v;
}

```ts
/**
 * The run of on-plan days ending at the most recent judged day. Walks history
 * backwards from `today` (exclusive: today is not judged yet) and stops at the
 * first day that is off plan or has no row at all.
 */
export function currentStreak(history: AdherenceHistory, today: string): number {
  const byDate = new Map(history.days.map(d => [d.date, d]));
  const d = new Date(today + "T00:00:00Z");
  let streak = 0;
  for (;;) {
    d.setUTCDate(d.getUTCDate() - 1);
    const iso = d.toISOString().slice(0, 10);
    if (history.firstLogDate && iso < history.firstLogDate) return streak;
    const day = byDate.get(iso);
    if (!day || day.state === "off") return streak;
    streak++;
  }
}
```

const POP_W = 194;
const GAP = 9;

export function CalDayPopup({
  cell, consumed, targets, rect, onClose,
}: {
  cell: CalCell;
  consumed: Macros | null;
  targets: Macros;
  rect: DOMRect;
  onClose: () => void;
}) {
  const [shown, setShown] = useState(false);
  const popRef = useRef<HTMLDivElement>(null);
  const [pos, setPos] = useState<{ top: number; up: boolean } | null>(null);

  // Measure once mounted, then reveal: below the chip if it fits, flipped above if not.
  useLayoutEffect(() => {
    const h = popRef.current?.offsetHeight ?? 0;
    const below = rect.bottom + GAP;
    const fits = below + h <= window.innerHeight - 12;
    setPos({ top: fits ? below : rect.top - h - GAP, up: !fits });

    const raf = requestAnimationFrame(() => requestAnimationFrame(() => setShown(true)));
    return () => cancelAnimationFrame(raf);
